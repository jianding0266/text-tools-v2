What Is Markdown?

Markdown is a lightweight markup language created by John Gruber in 2004. It uses plain text syntax to add formatting elements such as headings, bold text, italics, lists, links, and code blocks. Markdown is widely used for writing documentation, README files, blog posts, and formatted text in developer communities.

Markdown Syntax Cheat Sheet

  • Headings: Use # for H1, ## for H2, ### for H3, etc.
  • Bold: Wrap text in **text** or __text__
  • Italic: Wrap text in *text* or _text_
  • Links: Use [text](url)
  • Images: Use ![alt](url)
  • Code: Wrap inline code in backticks \code\
  • Lists: Use - or * for bullet lists, 1. for numbered lists
  • Tables: Use pipes | and hyphens - to create tables
