What Is a Case Converter?

A case converter is a text tool that transforms the capitalization of your text. It is commonly used when writing emails, editing documents, formatting code, or creating content for social media. Different writing conventions require different cases — for example, academic papers typically use sentence case for headings, while blog titles often use title case.

Six Case Formats Available

  1. Lowercase: Converts all characters to lowercase. Useful for normalization and data processing.
  2. Uppercase: Converts all characters to uppercase. Ideal for headers, emphasis, and acronym formatting.
  3. Title Case: Capitalizes the first letter of each word. Standard for headings, titles, and names.
  4. Sentence case: Capitalizes only the first letter of each sentence. Used in paragraphs and body text.
  5. Alternating case: Alternates between lowercase and uppercase for each character. A fun formatting style for creative projects.
  6. Reverse case: Swaps uppercase letters to lowercase and vice versa. Useful for stylistic effects.

How to Use the Case Converter

Simply enter or paste your text into the input box above, then click any of the six format buttons. The converted result appears instantly. You can copy the result with one click or clear the tool to start over. The conversion happens entirely in your browser — no data is sent to any server.
